Model Design

Mamba-Transformer V3 Architecture

A novel encoder-decoder combining Mamba state-space models for efficient long-range encoding with Transformer attention for precise generation.

01

Tokenization

SentencePiece 16K vocab, up to 2,048 input tokens

02

Chunk Split

8 non-overlapping windows of 256 tokens each

03

BiMamba Encoder

6-layer bidirectional SSM with forward+backward

04

Memory Compress

32 memory tokens per chunk via attention pooling

05

Cross-Chunk Attn

2-layer global context fusion across chunks

06

Transformer Dec

6 layers, gated cross-attention, SwiGLU FFN

07

Summary Output

Beam search decoding, up to 512 output tokens

Why It Works

Key Differentiators

What makes our model outperform generic pretrained models on clinical summarization.

Domain-Specific Training

Trained from scratch on 270K real MIMIC-IV clinical notes with a custom medical tokenizer.

270,031 samples

Mamba SSM Encoder

Bidirectional State Space Model processes long clinical notes in linear time complexity.

O(n) complexity

Memory Compression

Attention pooling compresses each chunk to 32 memory tokens for compact global representation.

256 → 32 tokens

Gated Cross-Attention

Learned gates control source information flow to each decoding step for factual consistency.

Adaptive gating

SwiGLU + RMSNorm

LLaMA-inspired gated activation and root-mean-square normalization for stable training.

LLaMA-inspired

Source Bypass

Decoder gets direct downsampled access to raw encoder output, grounding generation.

stride-8 bypass
